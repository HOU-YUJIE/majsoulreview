# 雀魂错题集

一个只在本机工作的 Windows 截图型错题集。程序不读取雀魂牌谱、网络、内存或账号信息，网页端和客户端均可使用。

## 使用方法

1. 启动 `MajsoulReview.exe`，点击左下角快捷键输入框并按下任意键或组合键，默认是 `F8`。
2. 在雀魂复盘中打开“错误一打”，按一次快捷键。
3. 首次使用时框选要保存的牌桌区域。程序会记住该区域。
4. 切换到“正确一打”，再次按快捷键。
5. 确认图片顺序，填写分类、标签和注释，然后保存。分类可以直接输入并添加，也可以删除不需要的分类。
6. 在主界面选择错题，先查看错误图，再点击“显示正确一打”。注释只会在此时显示。
7. 对照答案后点击“这次做对了”或“这次做错了”，程序会为每道错题分别累计次数。

“重新选择区域”会清除已记忆的裁剪区域。数据保存在 `%LocalAppData%\MajsoulReview`，可从程序底部直接打开或导出 ZIP 备份。

新截图会以 JPEG 质量 85 保存，最长边不超过 1600 像素，在保持牌面清晰的同时控制错题库体积。

## 构建

项目使用 .NET 8 WPF，不依赖第三方 NuGet 包。PowerShell 运行：

```powershell
.\build.ps1
```

发布自包含的 Windows x64 程序：

```powershell
.\build.ps1 -Publish
```

产物位于 `publish\MajsoulReview.exe`。构建脚本会在缺少 SDK 时将官方 .NET 8 SDK 下载到项目内的 `.tools` 目录，不修改系统安装。

## 当前限制

- 截图基于 Windows 桌面最终画面，目标窗口需要保持可见且不能被其他窗口遮挡。
- 若游戏处于独占全屏或截图为黑屏，请切换到无边框或窗口模式。
- 当前版本记忆一套裁剪区域；改变雀魂窗口布局后需要重新选择区域。
- 单独使用字母、数字等常用键作为全局快捷键会拦截该键在其他程序中的正常输入，建议使用功能键或带 `Ctrl`、`Alt`、`Shift`、`Win` 的组合键。
